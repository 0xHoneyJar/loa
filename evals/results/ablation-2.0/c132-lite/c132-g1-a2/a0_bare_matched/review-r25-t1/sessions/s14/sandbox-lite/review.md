head/evals/harness/ablation-grade.sh:1093 — [HIGH] Removal is keyed on the basename alone. It never checks that the other file with that basename is actually in the graded tree, and it never checks that the agent's file is in a package-less directory, which is the only case where pytest's default import mode fails with "import file mismatch". Two cases go wrong. (1) A refactor or feature agent moves or renames the fixture's tests/test_x.py to tests/unit/test_x.py: the original is gone, nothing collides, but the moved file is deleted, so the fixture suite or regression check loses those tests. (2) A same-name module inside a package (one with __init__.py) cannot collide, yet it is deleted too. A file should be removed only when its counterpart exists in the tree and both resolve to the same top-level module name.
