# Glossary: Loa

The terms people working on the Loa repository itself use, beyond the framework vocabulary in the framework glossary that ships with Loa. In other projects this file is the project glossary: the planning skills create it lazily at the project root the first time a term needs pinning, and update it inline.

## Language

**Cycle**: One numbered development iteration of the framework, from its requirements document through its sprints to the merged pull request and the archived records.

**Record branch**: A pushed branch that preserves a cycle's untracked review and audit records after the cycle merges, so the evidence outlives the working tree.

**Zone marker**: The temporary authorization a cycle creates at its start so that its own sprints may change the System zone, and deletes at its end.
