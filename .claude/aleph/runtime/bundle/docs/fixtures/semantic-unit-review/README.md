# Semantic unit review fixtures

The discovered `positive` child is a synthetic cumulative 1.7 manual-format
record. Its actor/pass declarations are fixture data: no human or model
review was executed. Its retained lock binds the prompt bytes used to build
the fixture, not the final implementation package.

`cases.json` supplies FX01–FX22 and their explicit alternative declarations.
Run `npm run test:semantic-review-contracts`,
`npm run test:semantic-review-mutations` and
`npm run test:semantic-review-process`.

The families cover conditional results, result/interpretation distinctions,
necessary and irrelevant context, referents, modality, comparators, metrics,
attribution, scope, qualifiers, recommendations, separable assertions,
inseparable context, semantic indeterminacy, unavailable material,
structural alternatives, predecessor compatibility, explicit no-claim,
source-composition couplings, narrower revisions and already-proposed S4
successors. All sources and reviewer declarations are synthetic.

The coherent semantic-error case intentionally passes structural checks.
Its proposed unconditional claim can be challenged by a semantic reviewer;
K2.19 has no answer key or deterministic assertion counter. Alternative
splits, facets and content roles can likewise pass when internally coherent.

The process suite invokes the existing worker transport and single writer
with fixture callbacks. It retains exact assignments, returns, execution
records and interrupted transactions. This is simulation, not evidence of
native fresh dispatch or production reachability. Manual actor distinctions
are declarations checked mechanically, not proof of cognitive independence.

No fixture establishes SRC-001 semantic correctness, replay, agent sanction,
acceptance, production readiness, golden status or Aleph v1. Slice 8 is not
part of these fixtures.
