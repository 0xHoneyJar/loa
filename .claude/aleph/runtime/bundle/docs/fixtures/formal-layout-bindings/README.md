# Formal / Table / Layout Bindings Fixtures

The positive child is a discovered cumulative 1.6 run. Inputs contain a
synthetic supplied table/flattened-formal export; the focused suite derives
FX01–FX17 companions and isolated invalid mutations from these captured bytes.
Structural PASS does not certify association meaning, formal interpretation,
semantic review, production execution, replay, sanction, acceptance, or v1.

Run `npm run test:representations` for the real checker CLI and generated
runtime comparisons. Every structural negative requires a nonzero exit,
K2.18, and its named reason token; the source-walk stale-review case requires
K2.14. `npm run test:representation-process` exercises the single-writer,
fresh-context transport, capture recovery, use recovery, and C1 boundaries.
All worker dispatch and authority actions in those tests are fixture-simulated.

| Cases | Structural expectation |
| --- | --- |
| FX01–FX02 | Declared table grid, spans, headers, caption and empty cell pass; inconsistent shifted coordinates fail. A coherent wrong-header association still passes. |
| FX03–FX05 | Flattened formal text, image-only chart and opaque pre-extraction capture retain honest limitations. Unavailable features cannot support usable interpretations; opaque extraction remains blocked. |
| FX06–FX11 | False fidelity/gold, missing headers, wrong coordinates, changed bytes, absent provenance and undeclared values fail their specific structural checks. |
| FX12–FX14 | Ordered/discontiguous and cross-page fragments, ambiguous captions, missing-header declarations, CRLF, glyphs, entities and significant spacing remain exact. |
| FX15–FX16 | Text-only 1.6 works with receipts; predecessor capabilities remain inactive and reserved-artifact injection fails. Existing accepted fixtures are not migrated. |
| FX17 | Supplied rendered formal bytes remain distinct from SRC bytes, with their own hashes and provenance. Removing rendering metadata fails. |

The must-pass variants include distinct supplied formal strings, alternate
captions/cell values/chart values, empty versus unavailable cells, and
overlapping regions. They assert mechanically consistent declarations, not
mathematical equivalence or correctness of meaning.

The coherent shifted-header case is a semantic adversary, not a negative
checker case. L2F must challenge whether the claim actually uses the right
header/caption, preserves glyphs and spacing, avoids equation reconstruction,
and avoids inferring values from images. These attacks have no deterministic
semantic answer key. A simulated verifier verdict does not establish that a
real reviewer performed or passed them.
