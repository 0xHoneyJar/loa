## Deliverables (in this order; each a file under `grimoires/loa/a2a/analysis-2026-10/`, summarised in `grimoires/loa/reports/ablation-2.0/analysis.md` at the end)

2. **Voice attribution** (`attribution.md` + `.json`): for every full-pipeline catch, which component first flagged it — the Fable reviewer's own `review.md`, the codex-headless dissent, the claude-headless companion, or the AUDIT gate — by matching each finding's file:line range to the planted label with the grader's matcher (extend `recall-vs-defects.sh`'s logic per voice; do not re-implement the matching rule). 3. **False-positive hand-label** (`false-positives.md` + a labelled CSV): a stratified sample of ~60 flagged regions (by arm and PR) from `grade.json recall.flags` outside any label, labelled independently by two Opus 5.5 subagents under one codebook (`real unplanted issue` / `style or preference` / `wrong`), each shown only the diff and the finding; report agreement (Cohen's kappa) and the corrected precision per arm with its interval; disagreements adjudicated by the lead and shown.
4. **Cost-effectiveness frontier** (`frontier.md`, a table and an ASCII chart): catch rate vs USD per PR for bare ×1, bare ×2 and ×3 (union, from the three trials), full, full-without-audit (reconstructed), full with the dissent's cost removed (a hypothetical, labelled); state the cheapest configuration reaching each catch-rate level.
