## Gotchas (all observed this cycle)

- zsh: `for x in $var` does not word-split; `${PIPESTATUS[0]}` is empty — gate commits with `out=$(cmd); grep -c '^not ok'` under `bash -c`; unquoted `--include=*.yaml` globs abort the line; a stray `'` inside `bash -c '…'` breaks parsing (write scripts to files under `~/.cache/loa/cycle-130/` and run them).
- `dec-write-lib.sh new`: `--summary` ≤ 160 characters including the `(Ln)` tag; `--recorded-by lead-seed` bare; failed calls do not consume ids — check which id landed before citing it.
- The fence blocks `git branch -D` and `rm -rf <var-path>` even inside heredoc or PR-body text; use `git branch -d`, `find … -delete`, explicit `/tmp/...` paths.
- Patch scripts: write with `os.replace` and restore the mode (`chmod 755`) — a plain rewrite dropped the grader's executable bit and failed 28 bats cases.
- `ablation-grade.bats` AG-13 forbids the literal `.claude/scripts` in the grader source, comments included.
- The stop guard blocks ending a turn while run mode is RUNNING or any background task/agent lingers: `TaskStop` idle implementer agents when their patch has landed; foreground `sleep` loops (≤ 600 s) for waits.
- The session can be suspended for hours while detached work runs; the batch breaker, the `--max-usd` reservation and the watchdog are the guards, not you.
- `spend.sh` must be given `--runs evals/results/ablation-2.0/smoke-258/rows.jsonl evals/results/ablation-2.0/runs.jsonl grimoires/loa/reports/ablation-2.0/runs.jsonl` (the default glob misses the ignored files) and does not see first-attempt costs of transport rows (STATUS `spend.ledger_usd`).
- `watch-batch2.sh` exits on `drift != null`, a cut above its baseline, a pause, spend above the threshold or the time cap; a batch resumed after a cut keeps the old record in `cuts[]` (pass the baseline count).
- Dissent diffs over ~10k lines time out the companion voice (KF-037); the diff helper already excludes fixtures, hidden material and reports.
- A1 review-catch runs cost REVIEW ≈ 5 + AUDIT ≈ 4–9 USD on the 5–8-defect PRs; size the review cap from that.
