## DECISION bullets

- DECISION: `--allow-unfrozen` bypasses both a missing MANIFEST.sha256 and a failing `freeze.sh --check` (drift or invalid suite), with a stderr warning and `suite_frozen: false` in grade.json. While D and E author tasks/, the smoke-only manifest drifts, so a missing-manifest-only bypass could not serve authoring.
- DECISION: added `--allow-partial` (passed to freeze.sh). The suite does not validate without it until sixteen tasks exist.
- DECISION: freeze.sh gets `--smoke` whenever MANIFEST.sha256 lists a `smoke/` path, so a manifest checks the way it was frozen, whatever `--tasks-dir` says.
- DECISION: pytest runs with `-rA` and exactly one `-q`. A doubled `-q` (-qq) drops the summary line. `-rA` gives the per-test outcomes the ids come from.
- DECISION: test ids are `t<k>`, k = position in file order (pytest: path, then def line; TAP: the test number). Regression ids are positions in the base run.
- DECISION: a pytest collection error expands to the test functions of its file. The hidden total is never below the static case count of the hidden files. A run without a summary is parse_error with total = max(static, 1); passed is 0 on a non-zero exit and total on exit 0.
- DECISION: host executor runs pytest as `python3 -P -m pytest` with `PYTHONUSERBASE=<caller's user base>`, because this host's pytest is user-site only (`-I`/`-s` would hide it).
- DECISION: a grader_protected path the fixture lacks is removed from the grading tree, so an agent-created pytest.ini or conftest.py on a protected path cannot persist.
- DECISION: a build fixture must resolve inside the task directory, or the grade is refused (exit 2), so freeze.sh covers it.
- DECISION: gates-combined.md holds normalised citations (`pr/head/` to `head/`, `a/` `b/` `/workspace/` dropped), one per line, deduplicated. Envelope findings contribute `anchor` and `file`+`line`; a hunk or symbol anchor without a line credits nothing.
- DECISION: `recall.flags` = recall-vs-defects' `findings_cited`. `recall.missed` lists defect positions (`d2`), never defect ids, because ids embed titles.
- DECISION: a gate "ran" when its feedback file exists. A file without a trailer is accuracy false. A0's `Verdict:` line in review.md fills `verdict` but never the per-gate accuracy.
- DECISION: snapshots graded are those a ran gate read (implement for REVIEW; fix1, else implement, for AUDIT). fix2 is not graded separately; final covers it.
- DECISION: churn is computed in Python (difflib) on the final tree against the fixture before restore and overlay, ignoring caches. It is null for review-catch.
- DECISION: contamination outside_path also allows the system directories in host mode, plus `~/.claude.json`. A one-component `/x/` Bash word counts as a regex, not a path (heuristic; lower bound, said in the header).
- DECISION: docker readiness (CLI and image) is checked only when a test will run, so review-catch grading needs no docker.
- DECISION: the bd-8o5rx exclusion applies to `fix` rows only (seed and `--build-manifest`). Defect labels on generated paths are kept, so defects[] stay unchanged; labels/*.tsv were not rewritten.
