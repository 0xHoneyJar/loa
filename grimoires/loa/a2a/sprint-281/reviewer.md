## Method (every pass)

1. Baseline with `hyperfine -N` (hyperfine 2.0 JSON, `.results[0].measurements[].time_wall_clock.value`) and a `PS4='+${EPOCHREALTIME} …' bash -x` trace (cProfile for Python) naming the hotspot and its share of wall time.
2. One lever per pass; a behaviour change counts as a failure even when it is an improvement; implement only at impact × confidence / effort ≥ 2.0.
3. Parity: the OLD file (`git show HEAD:<path>`) and the NEW file run side by side from mirrors in REAL directories (a symlinked hooks dir lets `..` escape to the live lib — pass 18 lesson) over the live inputs and an adversarial fixture matrix; `cmp` of stdout, stderr, exit code and every written file.
4. Roles: a Sonnet 5.5 implementer wrote the change and its REPORT.md; the Fable orchestrator re-derived parity and timing before every commit; a fresh-context Opus 5.5 reviewer with a hard time budget wrote `review/VERDICT.md` (APPROVE / CHANGES_REQUIRED); every CHANGES_REQUIRED was fixed and re-verified before the commit.
5. Each commit regenerated `grimoires/loa/REPO-MAP.md` + `.checksum` (the engine is inside its own scan); `.claude/checksums.json` was refreshed for all touched files at pass 18 and per commit afterwards (`check-loa.sh` passes on the head).
