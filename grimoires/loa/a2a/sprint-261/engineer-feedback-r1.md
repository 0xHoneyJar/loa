## Findings

### HIGH-1 — grader 1.2.11 `remove_colliding` can delete an agent's production module (DISS-001 + DISS-C-001, data-loss class; CONFIRMED, latent)
`evals/harness/ablation-grade.sh` (`def remove_colliding`): `reserved` takes the basename of every hidden-overlay `.py` (the v2 suites ship helper modules such as `tests/acceptance/_oracle_cron.py`) and of every `.py` under the fixture's `tests/`/`test/` (one fixture has `tests/helpers.py`), then walks the whole grading tree and unlinks any agent-added file with a reserved basename — inside real packages and under `src/` too. pytest's "import file mismatch" abort only concerns modules pytest collects (`test_*.py` / `*_test.py`) in package-less directories; a helper module or a packaged test module never collides. A feature-build or refactor agent that adds `src/app/helpers.py` would lose it before the hidden suite runs and a correct solution would grade as failing. **Evidence of no impact so far:** every real `grade.json` (227; 55 under 1.2.11) has `colliding_tests_removed` 0, so no row of any batch was touched; the defect is in the instrument, not in the data. **Required:** grader 1.2.12 — reserve only pytest-collectable test basenames (never `__init__.py`, `conftest.py` or helpers), from file overlays, directory overlays and the fixture test trees alike; remove only a candidate whose directory is package-less (no `__init__.py`); AG cases that fail on 1.2.11 and pass on 1.2.12; the official image self-check re-run; Sprint 262's Task 5.1 re-grade under the final grader shows no difference (expected, since the counter is 0 everywhere).

### MEDIUM-1 — directory overlays get no collision protection (DISS-002 + DISS-C-002; CONFIRMED, latent)
The same function records a directory overlay's dest in `owned_dirs` but never walks it, so its `.py` basenames never enter `reserved`; a hidden suite delivered as a directory could still abort collection against an agent file of the same basename. No v2 task uses a directory overlay (every `hidden/manifest.json` entry is a file), so the 1.2.11 guarantee holds for the frozen suite; fix with HIGH-1.

### MEDIUM-2 — the codex pre-flight horizon counts the whole plan on `--resume` and has no override (DISS-C-004; CONFIRMED)
