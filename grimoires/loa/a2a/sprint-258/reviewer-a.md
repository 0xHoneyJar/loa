## DECISION bullets

- DECISION: The compat library lives at `.claude/scripts/compat-lib.sh`, not `.claude/scripts/lib/compat-lib.sh` as the brief says. All new code sources that real path for `sha256_portable`.
- DECISION: gen-checksums hashes the working-tree content of each tracked path. A tracked path that is not a regular file in the working tree is skipped with a stderr warning, so `--check` reports a deleted tracked file as `removed`. Tracked path names containing a newline, tab or backslash are refused with exit 2.
- DECISION: The preflight count now uses `git ls-files -- .claude` minus overrides and the manifest. The count runs in the tree that owns the manifest: the `.loa` submodule when `.claude/checksums.json` is a symlink, as in a submodule mount. If that count is 0 it falls back to the legacy `find` count. That case covers being outside git, or a standard-mode downstream that does not track `.claude/`. Only the count block was changed.
- DECISION: `check_integrity` now ends with `return 0`. Before, a drift made the function return 1, and under `set -e` that ended check-loa.sh right after the integrity section. The baseline run shows this. The exit code is still 1 on any Tampered or Missing path, through FAILURES in `main`, and the later checks now run and report too.
- DECISION: not-mounted needs `.loa/.claude` to be a directory and `.loa/<manifest path>` to be a regular file. Anything else that is absent is Missing. A broken local symlink counts as absent.
- DECISION: The mount-scope bats seam is the existing `BASH_SOURCE` guard in check-loa.sh. Each case sources the script in a child bash and calls only `check_integrity`. The child exits 1 when FAILURES is non-zero, the same rule `main` uses. check-loa.sh was not changed for the test.
- DECISION: fresh-mount-proof's downstream entry point is `upstream/.claude/scripts/mount-submodule.sh --branch fresh-mount-proof --ref <sha> --force`, run with `LOA_UPSTREAM=file://<temp clone>`. It runs fully offline. Git is hermetic: no global or system config, a fixed identity, `protocol.file.allow=always` and an empty hooks path.
- DECISION: I added a `--worktree` flag to fresh-mount-proof that the brief does not list. It commits the source work tree's uncommitted state on a branch inside the temp clone only. Without it, the proof could only test committed code, and no commit is allowed in the worktree. The default (no flag) mounts REF as committed.
- DECISION: The CI step goes after "Knob readers go through profile-lib" and before the Python regression steps. Nothing that could write caches into the checkout runs before it.
- DECISION: No live-repo gen-checksums `--check` bats case; the CI step gates it. MP-6 covers the committed manifest.
