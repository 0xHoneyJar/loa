head/.claude/scripts/lib/dec-write-lib.sh:642 — `import` appends pending rows exactly as written. A hand-written `decisions-pending.yaml` row with `status: decided`, `decided_by: operator`, a `cli:` ref and a `proposed -> decided` transition `by: operator:decisions-command` gets imported into the live ledger (reproduced: exit 0, the row lands `decided`/`operator`). This skips `/decisions confirm` entirely, which the whole design rests on. Import should refuse any row past `proposed`, any non-null `decided_by`, and any `operator:` transition.

An agent can therefore make its own proposal come out `decided_by: operator` whatever the operator answered. The operator's own `--answer-ref cli:<now>` is silently dropped whenever a ref already exists (reproduced). `decided_by: operator` should come from the confirm-time operator reference, not from text the agent wrote earlier.
