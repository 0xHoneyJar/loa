## Finding

``` text
head/evals/harness/lib/seed_tasks.py:373 — The staging directory for a task id is never removed when its candidate fails its proof (or is refused by the post-build no-secrets scan). `main` calls `taken.discard(tid)` (lines 591/601), so the next candidate gets the same id, and `os.makedirs(stage/<tid>/fixture)` then raises FileExistsError, which is reported as `proof-failed`. One bad candidate makes every later candidate fail; refactor has the same problem at line 450. I reproduced it: with a cosmetic fix on top of a valid one, the output was `proof-failed …: [Errno 17] File exists: …/seed-stage.*/bugfix-01/fixture` and `written 0, proof failed 2`. Fix: `shutil.rmtree(os.path.join(stage, tid))` before reusing the id (or never reuse it).
head/evals/harness/lib/seed_tasks.py:570 — `selected = cands[: a.select]` is fixed before any task is built. A refactor candidate later skipped for "no test at the parent names a touched file", or a bugfix candidate refused by the secret scan, still uses up one of the N slots. This breaks the documented contract (seed-refactor-tasks.sh:115-116 "a commit without a covering test is skipped and does not count"; seed-bugfix-tasks.sh:43-44 "refusals and skips do not count"), so the seeder can write fewer than --select tasks while more candidates are left over.
head/evals/tests/ablation-grade.bats:16 — `BATS_BIN` is hard-coded to the operator's dotfiles (`$HOME/.local/dotfiles/tools/diff-so-fancy/test/bats/bin/bats`) and symlinked into the stub image …
```
