head/.claude/scripts/lib/dec-write-lib.sh:627 — `import` checks the pending file only with the plain schema validator (no base file, so it never compares against `proposed`), and nothing afterwards limits the imported rows to `open`/`proposed`. The row is then confirmed with `decided_by: agent` and `decided_by_ref: null`. I reproduced this. Operator confirmations made through `/decisions` are recorded as agent decisions with no way to fix them, because the ledger is append-only.
