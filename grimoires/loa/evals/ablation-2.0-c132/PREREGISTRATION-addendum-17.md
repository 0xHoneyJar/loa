## What the tooling does (DEC-0811)

`record_lite.py` (implementer C, verified by the lead) records, per run directory, a sandbox-lite set — `review.md`, every regular file under the sandbox's `grimoires/`, the sandbox copy of every file any key for the PR names as a defect file (the oracle-exposure check reads it), and every `pr/` file that is not byte-identical to the tracked fixture — plus `sandbox-manifest.json` (every sandbox entry with size and sha256, the pr/head and pr/base comparison with the fixture, the dropped and reconstructable counts). The grader reads nothing else under `sandbox/`: the findings files, the defect-file copies, and `pr/` (copied to `grading/pr`, whose symlink and oversize counts enter grade.json); the row writer reads the sandbox's a2a dissent envelopes, also in the lite set. Reconstruction rebuilds `sandbox/` from the tracked fixture's `pr-NN/{head,base,head.diff,PR.md}` plus the lite files, sha-checked against the manifest, beside the recorded `meta/`, `transcripts/`, `eval/` and `grading/gates-combined.md`.
