## 1. Question and construct

Does Loa's review pipeline (`a1_full`: Fable 5.1 REVIEW gate → AUDIT gate, each with the cross-model dissent, closed mount, eval config variant) catch more **confirmed defects** per dollar than a bare model given the same dollars, on pull requests it has never been evaluated on?

**Confirmed defect (the v2 label set):** a behaviour the fixture's head tree gets wrong that a hunk of `head..fix` changed, or that a post-merge incident (issue, Bridgebuilder round, KF entry, later fix commit on the same files within the merge-date → scan-date window) reported — as labelled independently by two blind annotators (Opus 5.5 sessions over packets holding only the codebook, the fix hunks with head context and the incidents; no feedback, labels, manifests or run directories) and adjudicated by the lead under written rules (DEC-0717, DEC-0719: anchors are the union of both annotators' in-hunk sites; one wrong behaviour per group; the same flaw on another code path is a member site, a helper, wiring or compiled copy is a follow-on; a malformed record is rerun blind, never edited). Every defect carries `label_source` (fix-commit | incident | fix-commit+incident), `agreement` (agreed | adjudicated) and `review_driven` (whether the round-1 review cited its site). The v2 key holds 185 defects over the 14 fixtures (153 review-driven; 5 incident-sourced; pooled hunk-verdict κ 0.878 over 835 hunks, incident κ 0.885 over 120 incidents, adjudication share 0.360; `grimoires/loa/a2a/sprint-269/annotation/result.md`). It is a lower bound on the real defects at head, and it is **not independent of the pipeline under test**: 153 of the 185 defects are review-driven — the round-1 review of that very PR (the same pipeline family) cited the site and the fix followed — so a re-run of the pipeline on the same input is graded against defects selected for being pipeline-findable. The expected direction of that bias is toward `a1_full`. Every conclusion is therefore restricted to the frozen known-defect set, every read is also reported stratified by `label_source` and `review_driven`, and the primary YES is reported conditional on the pipeline-independent read (§5, §6). An independent head-code audit that would add unreported or unfixed defects is out of this cycle's scope and is named as the follow-up. The frozen earlier sets stay as sensitivities (§10): the cycle-131 key (`manifests/c131/`, pr-11 … 18), the v1 key (`manifests/v1/`) and the seeded review-derived key (`manifests/review/`, all 14).

## 4. Validity, pairing, exclusions

A cell is valid when `status = completed`, every took-effect rule true (row `took_effect`), `contaminated` null on the row and the grade (classes 1–9, incl. network egress), `oracle_exposed_defects` empty (not applied to the open-mount arm), and no `refusal_fallbacks` on a non-matched cell; a matched cell is valid when ≥ ⌈k/2⌉ of its sessions are valid (infrastructure failures re-run ≤ 2 times; refusal-fallback and contaminated sessions kept as invalid, never re-run; SDD D-7.3). Unit = PR × trial pair; a pair enters the primary only when both arms' cells are valid (pairwise exclusion). The 25 % guard: an arm whose excluded share exceeds 0.25 marks the read inconclusive-by-degradation (figures still printed). No replacement trials. Dollar matching: a pair is matched when `|cost(matched) − cost(full)| ≤ 0.25 × cost(full)`, else flagged (the exact-dollar trim covers it). In a valid matched cell only the valid sessions contribute detections (the union) and `cost_usd`; invalid sessions' attempts are in `all_spend_usd`. Missingness is reported by arm and k with the two bounding sensitivities (excluded matched sessions as all-missed / all-caught), and the **all-assigned-pairs operational read** lists every planned pair with its outcome (completed, degraded, excluded, cut, not run), every failure class and all spend, with bounds for whole excluded pairs (the excluded arm's cell as all-missed and as all-caught). **Isolation:** every trial and every matched session runs in a fresh sandbox and HOME with no state carried between units, arms or trials. **Contract per arm:** the pipeline arms receive the PR under `pr/` through the closed mount (head overlay of the pinned framework; the eval config variant) and run the shipped review/audit skills; the BARE arms receive the same `pr/`, TASK.md and output contract with the bare prompt and the CLI's default tools and no framework; every sandbox has network for the model API only, and any repository egress is a class-9 contamination.

## 5. Primary and secondary estimands

**Primary:** Δ = recall(`a1_full`) − recall(`a0_bare_matched`), defect-weighted over the valid pairs (Σ caught / Σ defects per arm, the pm3 rule: a `head/<path>:<line>` citation within 3 lines of a key anchor, DEC-0638). Interval: the **cluster-t interval** Δ̂ ± t_{P−1} · SE · √(P/(P−1)) with P = valid PRs and SE from a paired cluster bootstrap resampling PRs with replacement (10,000; seed 20261021), 95 % (90 % beside); the percentile interval is printed as a diagnostic only (DEC-0711: it undercovers at small P). Corroborating reads: REML linear mixed model on cell recall with a PR random intercept (Wald 95 %; boundary flag); PR-level permutation test (all of a PR's cells swap arm together; 10,000; two-sided). Exchangeability assumption: under the null, which arm a PR's cells carry is exchangeable; trials of one PR are not.
**Secondary (each with cluster-bootstrap intervals):** PR-weighted Δ; recall and precision per arm (precision under the same pm3 rule); defects caught per USD per arm; cost per extra defect (full vs session-1 bare; full vs matched; on valid pairs and on all spend); `a1_review_only` − `a1_full`; `a1_full` − `a0_bare_fable_matched` (same-model contrast); the pipeline-independent read (defects with `review_driven = false` or `label_source` incident, from `labels_meta`); the dollar-matching table.
**What the primary measures:** anchor-proximity detection under the pm3 rule, not semantic agreement with the defect; the judge protocol (§9) is the semantic audit of that rule and the judge-corrected recall and precision are the stated semantic reads. **Co-reads reported beside the primary at every look and at the final:** (a) the pipeline-independent Δ (defects with `review_driven = false` or `label_source` incident; 32 + 5 defects — too few for the MDE, so its sign and interval qualify the primary, §6); (b) recall per arm stratified by `label_source` and `review_driven`; (c) the cost-matched Δ: the exact-dollar trim of the matched union to the full arm's realized cost (sessions in order 1 … k, whole sessions only, while the cumulative cost ≤ cost(full), at least session 1), on the pairs within the 25 % tolerance — the per-dollar read of the question; pairs outside the tolerance stay in the primary (same dollars by construction of k) and are listed. **Precision:** findings reduced to distinct cited regions (deduplicated by `cited_region`; a region crediting several defects counts once); false positives under the same pm3 rule. **Cost per extra defect:** defined when both the defect and the cost increments are positive; otherwise printed as dominated / dominated-by-cost with both increments. **Permutation null:** the sharp null that no arm has any effect on any PR — then the arm label of a PR's cells is exchangeable because both arms read the same PR under the same frozen contract; the test corroborates only and never enters the sequential decision; its size under heterogeneous effects is what the within-PR placebo measures (§8).
MDE 0.10 absolute recall; α 0.05 two-sided; target power 0.80 (achieved: §7).

## 6. Stopping rule

Looks after G1, G2, G3 (6, 10, 14 valid PRs); information fraction `t_k = SE²_planned-final / SE²_k` with the planned final SE 0.0286 (§7). Boundaries: Lan–DeMets O'Brien–Fleming spending (two-sided 0.05 for YES on `z_yes = Δ̂/SE`; one-sided 0.025 for NO on `z_no = (MDE − Δ̂)/SE`) on the cluster-t scale (df = P − 1), multiplied by the simulation-calibrated constant **1.00** (no inflation was needed: P(YES | Δ = 0) = 0.034 under the complete procedure). **Decision table (ordered, exhaustive; `reads-c132.py` implements it verbatim):** 1. z_yes ≥ b_yes and Δ̂ < 0 → **NEGATIVE** (the pipeline catches fewer); 2. z_yes ≥ b_yes, Δ̂ > 0, z_no < b_no and the RCI's upper end ≥ MDE → **YES**; 3. z_yes ≥ b_yes, Δ̂ ≥ 0 and (z_no ≥ b_no or the RCI's upper end < MDE) → **SMALL**; 4. z_yes < b_yes and z_no ≥ b_no → **NO**; 5. neither crossed at the final look → **INCONCLUSIVE**; 6. neither crossed before the final look: both conditional powers < 0.20 → **FUTILE** (non-binding: the lead may continue and must say so), else **CONTINUE**. **Looks** are taken when a scheduled group's batches complete (every planned pair resolved), whatever the valid-PR count then is; the information fraction uses the realized SE, forced monotone and ≤ 1 (t_k = min(1, max(t_{k−1}, SE²_planned / SE²_k))); a budget stop before the third group takes the final look at t = 1 on the realized data; no decision (CONTINUE) at any look with fewer than 6 valid PRs or 30 labelled defects, and a final look below those minima reads inconclusive-by-degradation. **Conditional YES:** a YES whose pipeline-independent Δ (§5) has a negative point estimate is reported as "YES on the review-derived key; not supported by the pipeline-independent defects"; a YES with a positive independent Δ is reported as YES. The final report prints the naive interval and the repeated confidence interval `Δ̂ ± b_k · SE` at the stopping look. Whether a rule fired and why is stated in one sentence.

## 8. Positive control and placebo

**Positive control:** `a1_full_openmount` − `a1_full` on every group's pairs (N PRs × 2 trials; excluding PRs whose closed-mount recall exceeds 0.9 — no headroom). Expected effect ≈ +0.07 (cycle-131 R1); with ~14 PRs the paired cluster-t SE is ≈ 0.03, so P(negative sign | +0.07) ≈ 1 % and the sign alone passes a true zero half the time — hence the table: **pass** = point estimate > 0 with oracle exposure in ≥ 2 open runs; **not demonstrated** = point estimate ≤ 0 with exposure but the 90 % interval covering 0, or exposure in only one run (every other read is reported "unconfirmed by the positive control", not void); **void** = the 90 % cluster-t interval entirely below 0 with exposure (the closed mount is then not shown to be the binding difference, and every other read is reported void); **not exercised** = no exposure in any open run, or fewer than 3 eligible pairs. Exposure is the oracle detector's per-run verdict (`oracle_exposed_defects` non-empty).
**Placebo:** 200 seeded within-PR arm-label shuffles (a PR's 2n cell results redistributed over its full and matched slots) through the primary read (1,000 bootstrap resamples each); pass when ≤ 8 % of the 95 % cluster-t intervals exclude 0 and |mean Δ| < 0.03 (DEC-0712). **Phase 0 result on the 63 existing rows** (`grimoires/loa/reports/ablation-2.0/placebo-existing/placebo-existing.md`, 21 pairs over 6 PRs, cycle-131 validity): **FAIL** — exclusion share 0.095 (percentile diagnostic 0.170), mean Δ −0.009 (bias passes), unshuffled Δ +0.284 [0.140, 0.427] (DEC-0714). Reading: the analysis manufactures no effect; at 6 clusters the cluster-t interval is anti-conservative on a shuffle mixture of a large real effect. The band is not loosened. **Pre-specified fallback:** the placebo runs again on the Phase 1 rows before `--final`; if it fails calibration there, the primary interval is printed beside its placebo-estimated exclusion share, and the decision rests on the calibrated group-sequential boundary (§6) and the PR-level permutation test, which the report says in one sentence. The fallback's size is what §7's simulation validated: the complete procedure (looks, boundaries, exclusions, partial groups) at N = 14 clusters under the fitted heterogeneous profiles gives P(YES | 0) = 0.034 (0.036 – 0.051 across the k, exclusion, ρ and spread scenarios); the permutation's size on the real rows is the placebo's exclusion share.

## 9. Judge protocol

Universe enumerated from the batch rows' run directories: credited and near-miss (citation, defect) pairs (near-miss = nearest citation in the same file within 4–20 lines), far-miss defects (no citation within 20 lines), stray citation regions.
