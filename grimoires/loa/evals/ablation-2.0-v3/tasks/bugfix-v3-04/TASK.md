# Task: the positive control follows the registered §8 table over every group, and every look reports the §5 co-reads

`evals/analysis/c132/reads.py` reads the cycle-132 ablation: `positive_control(cells, reg, seed)` contrasts the open-mount control arm against the full-pipeline arm (Δ̂ with a 90 % cluster-t interval, `ci90_t`) over the pairs of PRs both arms ran, and `--look N` writes `reads.json` / `reads.md` with the look table and its decision.

**Bug (observed):**
- The positive control is read over the first PR group only; a second group's open-mount runs are ignored (`n_prs`, `eligible_pairs`, `n_exposed_open_runs` count the first group alone).
- Its outcome rule is the pre-registration's original: `control not exercised` when no open run was exposed, else `pass` when Δ̂ > 0, `void` when Δ̂ < 0, `inconclusive` otherwise — one exposed run passes, any negative Δ̂ voids every other read, and fewer than three eligible pairs still decide.
- A look reports no co-reads.

**Expected:**
- `pc_outcome(n_exposed_open_runs, eligible_pairs, delta, ci90_t)` is the registered table, in this order: `not exercised` when no open run was exposed or fewer than 3 pairs are eligible; else `void` when the whole 90 % interval lies below 0 (one exposure is enough); else `pass` when at least 2 open runs were exposed and Δ̂ > 0; else `not demonstrated` (Δ̂ ≤ 0 with an interval covering 0, or a single exposure with Δ̂ > 0). `pc_outcome_pre_addendum_10(n_exposed_open_runs, eligible_pairs, delta)` keeps the old rule (`control not exercised` / `pass` / `void` / `inconclusive`, `inconclusive` also when Δ̂ is None).
- `positive_control` includes every group's PRs (eight PRs in two groups of six and two give `n_prs` 8, `eligible_pairs` 16, `n_exposed_open_runs` 16 when all were exposed, and `exposed_open_runs` names runs of the second group), and returns `outcome`, `outcome_pre_addendum_10`, `rule` = `§8 (addendum 10)`, `n_exposed_open_runs`, `eligible_pairs`, `n_prs`, `delta`, `ci90_t`, and `consequence`: `every other read void` for `void`, `every other read unconfirmed by the positive control` for `not demonstrated` and for `not exercised`, empty for `pass`.
- Every look's `reads.json` carries `co_reads` with exactly `look`, `pipeline_independent` (`status` `ok`, `n_defects` strictly between 0 and the full-pipeline arm's defect total), `stratified` (`review_driven` with strata `true`/`false`, `label_source` with `incident`/`fix-commit`; each stratum's per-arm `defects` partition the look's defects, so the two arms' sums agree) and `cost_matched` (`dollar_matching` with `n` equal to the look's `n_pairs` and `within`, and `n_pairs_within_tolerance` equal to `within`); `reads.md` gains the heading `## Co-reads (§5, reported at every look)`. The look's decision and Δ̂ are computed without the co-reads and are unchanged.

Fix the bug in place and add a regression test of your own. Run the tests under `evals/analysis/c132/tests` that cover the code you change, with `python3 -m pytest -q <file>`.
