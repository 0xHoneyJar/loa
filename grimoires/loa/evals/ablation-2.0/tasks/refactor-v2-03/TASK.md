# Task: give each ticketdesk desk its own explicit state

`ticketdesk` (under `src/ticketdesk/`) runs a small support desk: tickets with priorities, assignment to agents with a per-agent limit, SLA deadlines, an audit log and a replaceable clock. Its public face is `ticketdesk.Desk`. Behind it the state is spread over module globals. `config` holds a settings dict mutated by `configure()` and read through an `lru_cache`. `clock` holds the time source set by `set_clock()`. `store` keeps the tickets and a `global` id counter. `audit` keeps the event list. `service` and `reports` read all of it. Every new `Desk` resets the globals, so two desks in one process silently share and clobber each other's tickets, events, settings and clock.

**Refactor:**
- Add `ticketdesk.context.Context(*, sla_hours=None, max_open_per_agent=3, clock=None)`. It takes the settings `Desk` takes today and checks them on construction, raising `ValueError` with the existing messages. It holds one desk's settings, tickets, next ticket id, audit events and clock.
- Every public function (a module-level function whose name does not start with `_`) in `config`, `clock`, `store`, `audit`, `service` and `reports` takes the context as its first positional parameter, named `ctx`, and keeps its other parameters in their current order. For example, `service.open_ticket(ctx, title, priority="normal")` returns the new id, and `reports.workload(ctx)` reports only that context's tickets.
- `Desk` builds its own `Context` from its keyword arguments and passes it down. Two desks never share tickets, ids, events, settings or clocks.
- When you are done, no module in the package holds state of its own. Module-level assignments bind only constants: numbers, strings, `None`/`True`/`False`, names, and tuples or `frozenset(...)` of these, apart from `__all__`. A dict, list or set at module level is state, even when it is never mutated. The same rule holds for assignments in a class body, where a `dataclasses.field(...)` call is also allowed. No module uses `global` or `nonlocal`, decorates a function with `functools.cache` or `functools.lru_cache`, or defines a function named `configure`, `set_clock` or `reset`.

**Unchanged behaviour:** `Desk` keeps its constructor, methods, results and error messages. The existing suite must stay green without edits. Run it with `python3 -m pytest -q tests`.
